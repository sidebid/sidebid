Program upgrade authority

Private tool. Reads the program from chain and lets the authority wallet revoke, close or hand over the upgrade authority. Every transaction is simulated before the wallet is asked to sign.

Program

Wallet

Revoke: make the program permanent

This can never be undone. After revoke nobody, you included, can upgrade or close the program again. The deposit (the program data lamports) stays locked in the program forever.

Close: shut the program and take back the deposit

The program stops working the moment this lands. Every instruction fails, any SOL still held in program accounts (vaults, credits) is lost for good, and this program ID can never be used again. Drain everything first (withdraw-only shutdown).

Transfer the authority

The new address gets full control: it can upgrade, close or revoke. A wrong or unowned address loses control for good, and no signature from the new address is asked for. Check every character.
